
# This repository contains my Web Design 1 Assignment 1 project for Limkokwing University of Creative Technology, Sierra Leone.

The project demonstrates foundational skills in web development and version control using GitHub. It includes a simple HTML webpage (index.html) that presents my personal profile, including my bio, reasons for studying web design, and career goals.

## Key Features:
- Structured HTML page (Header, Body, Footer)
- Personal profile content
- Clean and simple web layout
- Version control using Git and GitHub

## Technologies Used:
- HTML5
- Git
